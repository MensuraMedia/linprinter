# Design: LinPrinter 0.2.1 (installer package, screenshots, polish)

## Why
The user asked that the git repository contain both the installer package and the installer script, with
proper screenshots and a robust README.

## Installer package
- A plain Debian package (`all`), built from the checkout by `tools/build-deb.sh`, with no build
  dependencies beyond dpkg-deb. It's committed in `dist/` with `SHA256SUMS`, so an offline machine
  needs only the repository (and, for dependencies, the linux-peripherals pool).
- It has no maintainer scripts: the desktop database and icon cache triggers update the menu. That
  keeps install and removal side-effect free.
- `Depends` comes from `app.json`, the same list `install.sh` and the offline pool use. A test keeps
  the three in step.
- `install.sh --package` is the recommended way to install the package:
  - it verifies the checksum before installing;
  - it reuses the same dependency step (offline pool first);
  - it removes the per-user menu entry, so the menu doesn't list LinPrinter twice.

## Screenshots
`tools/walkthrough.py` sets HOME and the XDG folders to a sandbox, creates sample documents (a report,
a photo and notes) and drives the real UI against the test printer. The shots therefore show `~/Documents/…`
paths, never the developer's files, and never print on hardware.

## Polish found through the screenshots
- The Profile row was placed above the Print Options title; it now sits under it.
- Home paths are shown as `~` on Printers and in the Print to PDF summary and result.
- The Recent columns fit a 1180 px window.
- The progress bar is cleared when another document is opened.
