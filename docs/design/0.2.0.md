# Design: LinPrinter 0.1 + 0.2 (released as 0.2.0)

## Goal
A USB printer companion for Linux, built like LinScanner: print with only the options the printer has,
preview exactly, follow jobs, see ink, and set up and test the printer. Print to PDF is always available.

## Methods and why direct IPP is preferred
1. **P1, direct IPP** to ipp-usb on 127.0.0.1. It gives full control of the job ticket (media-col with
   type and margins, borderless, quality), real job states and page counts, ink levels, and
   Identify-Printer. It needs no CUPS queue. The document is PWG raster rendered by Ghostscript, so what
   Preview shows is what prints.
2. **P2, CUPS**, for printers that need a driver, or if ipp-usb isn't answering. Options go through
   `lp -o` with standard IPP names; pages are pre-selected and pre-fitted.
3. **PDF**, Print to PDF. **T** is the test printer (development and tests only).

No fallback when the printer needs the user: another method would hit the same empty tray.

## Options come from the printer
`capabilities_from_ipp` builds sizes (grouped, with friendly names), types, colours, qualities, copies,
sides and borderless combinations from media-col-database, plus margins and the printer's defaults.
Controls hide or disable what isn't supported. For example, borderless is offered only for sizes and
types the printer lists with zero margins.

## Setup and test (added at the user's request)
The printer can't be configured over IPP (no Set-Printer-Attributes). So LinPrinter:
- shows and can adopt the printer's own defaults;
- prints its own test pages, built to the printer's paper and margins;
- runs Identify and shows ink levels and alerts;
- opens the printer's settings / maintenance and ink pages, and only when they are served on localhost
  over USB.

## Privacy
USB only, loopback IPP only, no discovery on the network, redacted logs, temporary files deleted at exit,
and printer web pages opened only on localhost.

## Tests
There are 32 tests: codec round-trips; ipptool interop; capabilities and defaults from the fixture; status
words; CUPS parsers; page selection; PWG / PDF / preview / test-page rendering; the full print flow on
the test printer (job attributes, paper-out without fallback, Print to PDF, test page not in Recent); a
UI flow; and redaction.
