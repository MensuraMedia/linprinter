# LinPrinter

A printing app for Linux in the style of
[LinScanner](https://github.com/MensuraMedia/linscanner). It follows the same
interface, modular feature design, USB-only privacy and universal approach:
driverless IPP Everywhere through CUPS and ipp-usb, with CUPS drivers as the
fallback.

**Status: concept.** Nothing is built yet. Read the technical concept, based
on the connected Canon TR150 series:
[`docs/CONCEPT.md`](docs/CONCEPT.md).

| | |
|---|---|
| Target printer | Canon TR150 series (USB, IPP-over-USB, driverless) |
| Platform | Linux desktop, GTK 3 (the gtk-python-dashboard-starter framework, as in LinScanner) |
| Sibling projects | [LinScanner](https://github.com/MensuraMedia/linscanner) · [linux-peripherals](https://github.com/MensuraMedia/linux-peripherals) |
